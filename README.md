`class Smartphone(Product)` - Создание объектов товаров подкласса продуктов

`class LawnGrass(Product)` - Создание объектов товаров подкласса продуктов

`class Category` - Создание групп товаров

`class CategoryIterator` - Итератор перебора продуктов в категории продуктов
